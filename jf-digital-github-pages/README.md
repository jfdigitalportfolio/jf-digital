# JF Digital Portfolio

A free, static black-and-gold portfolio website for JF Digital.

## Publish on GitHub Pages

1. Upload `index.html`, `style.css` and `script.js` to the **root** of your `jf-digital` repository (not inside a folder).
2. Open the repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main**, folder **/(root)** and click **Save**.
5. Wait for GitHub to deploy, then open your Pages link.

## Contact button

The contact button is deliberately disabled until you supply a business email address. To enable it, open `script.js` and set `BUSINESS_EMAIL` to your chosen public business email. Never add private contact details you do not want visible on the internet.

## Notes

- Three external links lead to fictional concept websites.
- Stock photographs are remotely hosted by Unsplash and require an internet connection. Check the applicable image licences and replace any image if necessary.
- Fonts are served from Google Fonts; fallback fonts are included.
- No backend, paid API, AI credits or database is required.
- This is a public portfolio: do not add sensitive personal information.
